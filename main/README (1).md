# 🚦 駕照別忘光！｜台灣交通安全互動學習平台

這是一個結合「駕照知識複習」與「道路情境闖關」的純前端互動式交通安全教育網站，採用原生 **HTML5 + CSS3 + JavaScript (ES6+)** 開發，無需後端資料庫或任何付費 API，可直接上傳至 **GitHub Pages** 免費架站執行！

## 📁 專案檔案結構

```text
├── index.html   # 網站主架構與五大頁面視圖（首頁、知識複習、筆試測驗、情境闖關、學習紀錄）
├── style.css    # 響應式介面樣式（淺藍＋純白＋號誌黃設計、卡片式排版、RWD 手機適配）
├── script.js    # 獨立題庫／標誌／情境關卡資料結構、答題計分與 localStorage 進度管理
└── README.md    # 專案說明與 GitHub Pages 部署教學
```

## ✨ 主要功能特色

1. **首頁總覽**：原創交通安全 SVG 路口插畫、即時學習進度儀表板與四大功能快速入口。
2. **交通知識複習**：涵蓋「交通標誌認識（可點擊檢視詳細圖解說明）」、「道路交通規則」、「汽車行車安全」、「機車行車安全」與「行人安全」五大單元。
3. **駕照筆試測驗**：支援汽車／機車／綜合／錯題收藏本分類抽題，作答後立即顯示正確答案與台灣現行法規解析，並可收藏錯題反覆練習。
4. **道路情境闖關（7 大實戰關卡）**：包含十字路口通行、汽車右轉遇行人、機車變換車道、閃光紅黃燈路口、無號誌同寬路口會車、避讓救護車及夜間雨天行車，配備專屬路況俯視模擬圖與關卡解鎖機制。
5. **學習紀錄與成就徽章**：自動將積分、正確率、闖關進度與收藏題目儲存於瀏覽器 `localStorage`，並設有 6 項安全駕駛榮譽徽章。

## 🚀 如何在 GitHub Pages 上執行

1. 在 GitHub 建立一個新的公開儲存庫（Repository），例如 `dont-forget-your-license`。
2. 將 `index.html`、`style.css`、`script.js` 與 `README.md` 上傳至該儲存庫的根目錄。
3. 前往儲存庫的 **Settings → Pages**，在 **Branch** 選擇 `main`（資料夾選 `/ (root)`）並點擊 **Save**。
4. 等待約 1～2 分鐘，即可透過 `https://<你的帳號>.github.io/dont-forget-your-license/` 線上瀏覽與分享！
